# Example mission — draft template

## Outcome

Describe one observable result and why it matters.

## Starting Evidence

List inspected code, observed behavior, starting revision and unresolved uncertainty. Replace this prose with real evidence.

## Decisions and Constraints

Record accepted choices and link the existing authoritative documents. Keep proposals separate.

## Scope

List included work, exclusions and authorized actions. No implementation, delegation, commit or deployment authority is granted by this template.

## Validation Contract

Specify a positive case, legitimate counterexample, failure state, focused checks, real-use verification and evidence needed. Explain non-applicable layers.

## Execution Boundaries

State what the principal agent and any worker may decide and what must return to the user. Record scoped implementation/review authority when given, or leave it explicitly unresolved. Keep the selected mode in execution state with its decision evidence. Use the execution reference for mode selection and packet boundaries. Resolve blockers before ready.

## Completion

State deliverables and independent acceptance evidence. A completed template is not a completed mission.
