Tool references written as `@<group>` identify tool groups rather than callable tools. The harness expands these aliases. If you need to understand a group's membership, consult the effective configuration: global `~/.pi/agent/tool-groups.json`, trusted project `.pi/tool-groups.json`, and any `toolGroups.groups` settings overrides. Groups may contain nested aliases. Call concrete tools exposed in your current session. Group membership alone does not establish availability.
